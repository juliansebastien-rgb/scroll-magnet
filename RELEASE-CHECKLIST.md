# Release Checklist

## GitHub

- Update plugin version in `scroll-magnet.php`
- Update `Stable tag` in `readme.txt`
- Update `README.md` and `CHANGELOG.md`
- Build the plugin ZIP
- Commit and push to `main`
- Create a Git tag like `v0.2.0`
- Create a GitHub release and attach the ZIP asset

## WordPress.org Later

- Prepare plugin icon
- Prepare banner image
- Prepare at least one admin screenshot
- Review `readme.txt` sections for the plugin directory
- Publish the free version

## Premium Later

- Add click/view dashboard improvements
- Add conversion templates
- Add A/B testing
- Add combined trigger rules
