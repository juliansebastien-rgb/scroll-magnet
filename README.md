# Scroll Magnet

Scroll Magnet is a WordPress plugin that displays conversion-focused calls to action based on how far a visitor has scrolled through a page.

Instead of using generic popups, the plugin helps site owners trigger different messages at different engagement levels:

- 50% scroll: discovery CTA
- 70% scroll: reassurance CTA
- 90% scroll: final conversion push

## Version 0.2.0

- 3 configurable scroll triggers
- 3 display formats: bottom banner, floating button, soft popup
- Custom message, button label and target URL
- Simple targeting: all content, posts only, pages only, specific page IDs
- Front assets only load when the plugin is active and relevant
- Basic view and click tracking per trigger
- Live admin preview
- GitHub-based plugin update support

## Installation

1. Upload the `scroll-magnet` folder to `/wp-content/plugins/`
2. Activate the plugin in WordPress
3. Go to `Settings > Scroll Magnet`
4. Configure the triggers and save
